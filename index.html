02

The language · ~7 min

Python in 7 minutes

You only need three ideas to do real data work: variables, lists, and DataFrames. Everything else follows from these.

⏱ ~7 minutes · follow along, then experiment

Python reads almost like English. That's intentional — it was designed to be understandable by humans first, computers second. Let's start with the absolute basics.

Cell 2 — Variables & lists
basics.py
# A variable is a labelled box that stores a value school_name = "UIUC" # text (called a "string") year = 2024 # a whole number gpa = 3.85 # a decimal number is_fun = True # a yes/no value (Boolean) print(school_name) # → UIUC print(year + 1) # → 2025 (math works!) print(f"GPA: {gpa}") # → GPA: 3.85 # A list holds multiple values in order (like a spreadsheet column) majors = ["ID", "GD", "Arch", "GD", "ID"] scores = [87, 94, 78, 91, 82] print(majors[0]) # → "ID" (counting starts at 0!) print(len(scores)) # → 5 (how many items) print(sum(scores) / len(scores)) # → 86.4 (the average)
⚠
Counting starts at zero. majors[0] gives the first item, majors[1] gives the second. This trips up almost everyone at first — you'll get used to it in about 10 minutes.
Cell 3 — The DataFrame (your spreadsheet in Python)
dataframe.py
# A DataFrame is a spreadsheet — columns of related data # We build one by giving pandas a dictionary: { column_name: [values] } data = { "name": ["Alex", "Jordan", "Sam", "Taylor", "River"], "major": ["ID", "GD", "Arch", "GD", "ID" ], "projects": [12, 8, 15, 10, 9 ], "grade": [3.7, 3.2, 3.9, 3.5, 3.4 ] } df = pd.DataFrame(data) # pd is our alias for pandas print(df) # show the whole table print(df["grade"].mean()) # average of the grade column → 3.54 print(df.describe()) # summary stats: mean, min, max, etc.
💡
Mental model: Think of a DataFrame like an Illustrator artboard with organized layers. Each column is a category of information, each row is one "thing" (a person, a product, a data point). Almost everything in data analysis is transforming this table.

Run both cells. You should see your table printed with all five students. That's real data — you built it from scratch. Try adding a sixth student by adding their info to each list, then re-running.

03

Visualization · ~8 min

Your first chart

Two lines of code. A real chart. Then we'll make it beautiful.

⏱ ~8 minutes · run each cell, discuss what changes

Seaborn is built on top of matplotlib and handles all the aesthetic decisions for you by default. Let's start with the simplest possible chart and build up from there.

Cell 4 — The simplest possible chart (2 lines)
first_chart.py
# sns.set_theme() applies beautiful defaults — always call this first sns.set_theme(style="whitegrid", palette="muted") # That's it. Two lines to make a chart. sns.barplot(data=df, x="name", y="projects") plt.show() # renders the chart
👁
You should see: A clean bar chart with the five student names on the x-axis and their project counts on the y-axis. Height encodes quantity — taller bar = more projects.

Now let's add more information to the same chart by using color as a second visual channel. This is exactly how information designers think — every visual property (position, size, color, shape) can encode a dimension of data.

Position (x) → name
Height (y) → # of projects
Color (hue) → major
Cell 5 — Color as information
color_chart.py
# fig, ax = the canvas and the drawing area # figsize = (width, height) in inches fig, ax = plt.subplots(figsize=(8, 5)) sns.barplot( data=df, x="name", y="projects", hue="major", # color encodes major (try "grade" instead!) palette="Set2", # try: "pastel", "husl", "muted", "dark" ax=ax ) ax.set_title("Projects completed by student", fontsize=14, pad=12) ax.set_xlabel("Student") ax.set_ylabel("Projects completed") ax.legend(title="Major") ax.spines["top"].set_visible(False) # clean up the frame ax.spines["right"].set_visible(False) plt.tight_layout() plt.show()
🎨
Try this: Change palette="Set2" to palette="pastel", then to palette="dark". Re-run the cell each time. As a designer, choosing a palette is often the most consequential decision you'll make for a visualization.

"Every pixel in a data visualization should earn its place. Remove anything that doesn't communicate information."
— Edward Tufte, data visualization pioneer

📊
Bar chart
Compare quantities across categories. Bar height = amount. Best for: survey results, rankings, comparisons.
📈
Line chart
Show change over time. The slope tells the story. Best for: trends, time series, progress.
⭕
Scatter plot
Show relationships between two variables. Each dot = one thing. Best for: correlations, clusters.
🔥
Heatmap
Show intensity across two categories. Color = value. Best for: matrices, frequency tables.
04

Real-world data · ~8 min

Working with real data

Seaborn ships with real research datasets. We'll use penguin measurements from Antarctica — 344 birds, 3 species, collected by real scientists.

⏱ ~8 minutes · explore, don't just run

Real datasets are messier, larger, and more interesting than example data we write by hand. The Palmer Penguins dataset is a staple of data science teaching — it's beautiful to visualize and has rich structure to discover.

Cell 6 — Load & explore the dataset
load_data.py
# Load the built-in penguins dataset (real Antarctic research!) penguins = sns.load_dataset("penguins") # Always explore before you visualize print("Shape:", penguins.shape) # (344, 7) → 344 rows, 7 columns print("\nColumns:", penguins.columns) # what data do we have? print("\nFirst 5 rows:") print(penguins.head()) print("\nSpecies in the dataset:") print(penguins["species"].value_counts()) # how many of each? print("\nSummary statistics:") print(penguins.describe())
🐧
What you'll see: 344 penguins measured by flipper length, bill dimensions, body mass, and island location. Three species: Adelie (152), Chinstrap (68), Gentoo (124). Some rows have missing values — describe() only shows you the rows with complete data.
Cell 7 — Scatter plot with three visual encodings
scatter.py
# This single chart encodes four variables simultaneously: # x position → flipper length # y position → body mass # color → species # shape → species (redundant encoding = more accessible!) fig, ax = plt.subplots(figsize=(9, 6)) sns.scatterplot( data=penguins, x="flipper_length_mm", y="body_mass_g", hue="species", style="species", # shape redundancy helps colorblind readers palette=["#E8593C", "#3B8BD4", "#1D9E75"], alpha=0.8, # transparency for overlapping points s=80, # dot size ax=ax ) ax.set_title("Antarctic Penguins · Flipper Length vs Body Mass", fontsize=14, pad=12) ax.set_xlabel("Flipper Length (mm)") ax.set_ylabel("Body Mass (g)") ax.spines["top"].set_visible(False) ax.spines["right"].set_visible(False) plt.tight_layout() plt.show()
✨
Notice: The three species form distinct clusters — you can see the pattern emerge without being told what to look for. That's the power of good visualization. It reveals structure that was invisible in the raw numbers. Now try changing "flipper_length_mm" to "bill_length_mm" — how do the clusters shift?
🔬
You're doing exploratory data analysis. EDA is what data scientists spend 60–70% of their time doing — looking at data from different angles to understand its structure before drawing conclusions. You just did it.
05

The capstone · ~12 min

The finale

A multi-panel publication-quality figure. The kind you see in research papers and data journalism. Yours to download and put your name on.

⏱ ~12 minutes · read the code before running it
★  Capstone piece — save & share this one

This is a four-panel figure — a layout technique from scientific publishing that tells a richer story than any single chart can. Each panel uses a different chart type, but they share a color palette and title system that makes them feel like one cohesive piece.

Read through the entire code first. Every section is commented. By the time you run it, you should understand every line.

Cell 8 — The final publication-quality figure
final_visualization.py
# ───────────────────────────────────────────────── # SETUP: Define our custom color palette # These hex codes are chosen for contrast & accessibility # ───────────────────────────────────────────────── SPECIES_COLORS = { "Adelie": "#E8593C", # warm coral-red "Chinstrap": "#3B8BD4", # ocean blue "Gentoo": "#1D9E75" # Antarctic teal } # Remove rows with any missing values penguins_clean = penguins.dropna() # Set the overall visual theme sns.set_theme(style="white", font_scale=0.9) # ───────────────────────────────────────────────── # LAYOUT: A 2×2 grid using GridSpec for precise control # figsize is the overall canvas in inches (width, height) # ───────────────────────────────────────────────── fig = plt.figure(figsize=(14, 10)) gs = fig.add_gridspec(2, 2, hspace=0.45, wspace=0.35) ax1 = fig.add_subplot(gs[0, 0]) # top-left ax2 = fig.add_subplot(gs[0, 1]) # top-right ax3 = fig.add_subplot(gs[1, 0]) # bottom-left ax4 = fig.add_subplot(gs[1, 1]) # bottom-right # ───────────────────────────────────────────────── # PANEL A · Scatter: Flipper length vs body mass # Shows the relationship between two continuous variables # ───────────────────────────────────────────────── sns.scatterplot( data=penguins_clean, x="flipper_length_mm", y="body_mass_g", hue="species", style="species", palette=SPECIES_COLORS, alpha=0.75, s=55, ax=ax1, legend=False ) ax1.set_title("A · Flipper length vs body mass", fontweight="bold", fontsize=11) ax1.set_xlabel("Flipper length (mm)") ax1.set_ylabel("Body mass (g)") ax1.spines[["top", "right"]].set_visible(False) # ───────────────────────────────────────────────── # PANEL B · Violin: Body mass distribution by species # A violin shows the full distribution shape, not just the mean # The width at each height = how many penguins are that size # ───────────────────────────────────────────────── sns.violinplot( data=penguins_clean, x="species", y="body_mass_g", palette=SPECIES_COLORS, inner="quartile", # shows median + quartiles inside ax=ax2 ) ax2.set_title("B · Body mass distribution", fontweight="bold", fontsize=11) ax2.set_xlabel("Species") ax2.set_ylabel("Body mass (g)") ax2.spines[["top", "right"]].set_visible(False) # ───────────────────────────────────────────────── # PANEL C · Heatmap: Average mass by island & species # pivot_table() reshapes data — like Excel's PivotTable # ───────────────────────────────────────────────── pivot = penguins_clean.pivot_table( values="body_mass_g", index="island", columns="species", aggfunc="mean" # "mean", "count", "sum" all work ) sns.heatmap( pivot, annot=True, fmt=".0f", # show values, no decimals cmap="YlOrRd", # yellow → orange → red linewidths=0.5, cbar_kws={"label": "Avg mass (g)"}, ax=ax3 ) ax3.set_title("C · Average mass by island & species", fontweight="bold", fontsize=11) ax3.set_xlabel("Species") ax3.set_ylabel("Island") # ───────────────────────────────────────────────── # PANEL D · Histogram: Bill depth by species # Overlapping histograms show how distributions compare # ───────────────────────────────────────────────── for species, color in SPECIES_COLORS.items(): subset = penguins_clean[penguins_clean["species"] == species] ax4.hist( subset["bill_depth_mm"], bins=18, alpha=0.55, color=color, label=species, edgecolor="white", linewidth=0.5 ) ax4.set_title("D · Bill depth distribution", fontweight="bold", fontsize=11) ax4.set_xlabel("Bill depth (mm)") ax4.set_ylabel("Count") ax4.legend(title="Species", fontsize=9) ax4.spines[["top", "right"]].set_visible(False) # ───────────────────────────────────────────────── # TITLE: A master headline for the whole figure # suptitle sits above all panels # ───────────────────────────────────────────────── fig.suptitle( "Palmer Penguins · Antarctic Species Analysis", fontsize=17, fontweight="bold", y=1.02 ) fig.text( 0.5, 0.985, "Data: Palmer Station LTER / K. Gorman (2020) · Visualization by [your name]", ha="center", fontsize=9, color="#999" ) # ───────────────────────────────────────────────── # EXPORT: Save as a high-resolution PNG image # dpi=200 is print-quality. bbox_inches="tight" prevents clipping # ───────────────────────────────────────────────── plt.savefig( "penguins_analysis.png", dpi=200, bbox_inches="tight", facecolor="white" ) plt.show() print("✅ Saved! Go to Files (folder icon) → right-click → Download")
💾
To download your chart: In Colab, click the folder icon in the left sidebar. Find penguins_analysis.png. Right-click it and choose Download. That's a 200 DPI image — it'll look sharp on screen and in print.
